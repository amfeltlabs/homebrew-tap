# homebrew-tap

A [Homebrew](https://brew.sh) tap for the Amfelt agent, `amfelt`.

**Status:** no formula is published here yet. The tap cannot install the agent today.

The formulae will be generated from the Amfelt release channel at `https://releases.amfelt.com`: the URL and the sha256 of each archive come from the channel's signed checksums file. Do not edit the formulae by hand.

The agent is licensed under the Amfelt binary EULA: <https://releases.amfelt.com/LICENSE-BINARY>. This repository holds formulae only.
